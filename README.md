# Лабораторная работа №4. Mesto

Вариант 17. Валидация форм, сборка Vite, поле «Приоритет показа» от 1 до 10
и показ карточек порциями по 4 с кнопкой «Показать ещё».

## Запуск

Нужен Node.js 20.19+ из ветки 20 либо версия 22.12 и выше.

```sh
npm ci
npm run dev
```

Браузер откроется автоматически. Адрес сервера появится в терминале.

## Сборка

```sh
npm run build
npm run preview
```

Готовая сборка находится в `dist/`. Для просмотра используй сервер,
а не открытие `index.html` двойным кликом.

## Проверка

```sh
npx playwright install chromium
npm test
```

Проверяются валидация, сброс форм, профиль, аватар, карточки и пагинация.

## Что сдавать

Отчёт находится в `report/Отчёт_ЛР4_вариант_17.docx`.
Заполни поля в квадратных скобках на титульном листе и ссылку на свой
публичный репозиторий GitHub. Затем загрузи туда исходники вместе с
`package.json` и `package-lock.json`. Папки `node_modules/` и `dist/`
загружать не нужно.

Основа проекта: https://github.com/Yandex-Practicum/mesto-ad.
